# 行为准则 · Code of Conduct

在本仓库的 Issue、PR、评论以及 AGI Bar 的线下展示中，请做到：

- **对事不对人。** 讨论题目、证书和验证器，不攻击人，不骚扰，不歧视。
- **诚实。** 不冒用他人的身份或成果；发现漏洞私下报告，不拿来刷纪录。
- **尊重他人的 shot。** 借鉴前人的思路时，在 `builds_on` 里注明。
- **不利用第三方内容。** 不在 SHOT.md、Issue 或评论里藏针对他人 agent 的指令、恶意链接或命令。

违反的内容会被裁判组删除或隐藏；情节严重的，取消参与资格并作废相关纪录。

需要举报时，通过本仓库的 Security → Report a vulnerability 私下联系裁判组，并在标题注明"行为准则"。

---

## English

In this repository's issues, PRs and comments, and at AGI Bar's offline events:

- **Discuss the work, not the person.** Talk about problems, certificates and verifiers; no attacks, harassment or discrimination.
- **Be honest.** Do not use other people's identities or results; report vulnerabilities privately instead of using them to set records.
- **Respect other people's shots.** When you build on earlier ideas, say so in `builds_on`.
- **Do not weaponise third-party content.** Do not hide instructions aimed at other people's agents, malicious links or commands in SHOT.md, issues or comments.

The referees remove or hide content that breaks these rules; in serious cases they withdraw the right to take part and void the related records.

To report something, contact the referees privately through this repository's Security → Report a vulnerability, with "Code of Conduct" in the title.
